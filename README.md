# My Projects Page

A responsive **My Projects Page** created using **HTML, CSS, JavaScript, Bootstrap integrations, and CCBP UI Kit display utilities**.

This project showcases my web development projects in a clean and responsive layout.

## 🌐 Live Demo

👉 **[My Projects Page](https://my-projects-page-delta.vercel.app/)**

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- CCBP UI Kit Display Utilities

## ✨ Features

- Responsive design
- Clean and simple user interface
- Bootstrap integrations
- CCBP UI Kit display utilities
- Responsive project cards
- Easy navigation
- Mobile-friendly layout

## 🎯 Purpose

The purpose of this project is to create a personal projects page where I can showcase my web development projects and practice frontend development skills.

## 🛠️ Bootstrap & CCBP UI Kit

This project uses **Bootstrap integrations** to create responsive layouts and styling.

The **CCBP UI Kit display utilities** are used to control the display and visibility of elements and help create responsive webpage layouts.
